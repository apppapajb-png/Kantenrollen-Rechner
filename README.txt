KANTENROLLEN-RECHNER – iPhone & Android PWA

INHALT
- index.html
- manifest.webmanifest
- sw.js
- icons/icon-192.png
- icons/icon-512.png

WICHTIG:
Für die Installation als richtige Homescreen-App mit Offline-Cache muss dieser
Ordner über HTTPS bereitgestellt werden. Ein direktes Öffnen der index.html
eignet sich zum Testen, installiert aber nicht zuverlässig eine PWA.

INSTALLATION NACH BEREITSTELLUNG:
iPhone/iPad (Safari):
1. App-Webseite öffnen.
2. Teilen-Symbol antippen.
3. „Zum Home-Bildschirm“ wählen.
4. „Hinzufügen“.

Android (Chrome):
1. App-Webseite öffnen.
2. Browser-Menü öffnen.
3. „App installieren“ bzw. „Zum Startbildschirm“ wählen.

Die App rechnet vollständig lokal und benötigt nach dem ersten Laden keine
Internetverbindung.
